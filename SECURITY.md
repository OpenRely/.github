# Security Policy

OpenRely and its community take security seriously. We appreciate your efforts to responsibly disclose vulnerabilities.

## Supported Versions

Security updates and patches are applied to the latest active development and release branches across OpenRely projects:

| Project / Version | Supported          |
| ----------------- | ------------------ |
| Main branch       | :white_check_mark: |
| Latest Release    | :white_check_mark: |
| Older Releases    | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report vulnerabilities using one of the following methods:

1. **GitHub Private Vulnerability Reporting (Preferred)**: Navigate to the `Security` tab of the affected repository and click **"Report a vulnerability"**.
2. **Security Contact**: Email our maintainers at [security@openrely.ai](mailto:security@openrely.ai).

### What to Include in Your Report

To help us triage and resolve the issue quickly, please provide:
- A clear description of the vulnerability and potential impact.
- Step-by-step instructions or proof-of-concept (PoC) to reproduce the issue.
- The software version, commit hash, and environment details.
- Any suggested mitigations or patches, if available.

### Our Commitment

- We will acknowledge receipt of your report within **48 hours**.
- We will coordinate with you during the investigation and provide status updates.
- Once fixed, we will publicly credit you in our release notes (unless you prefer anonymity).
